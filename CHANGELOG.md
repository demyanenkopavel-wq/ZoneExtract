# Changelog

## 2.0.0 — first public release

- English interface (View → Language), Russian stays the default for Russian systems.
- Built-in demo: a generated sample PDF and a ready template (Help → Demo).
- First template wizard (Templates → First template wizard).
- 🔮 takes the text sample straight from the open PDF; “Detect type for all fields” button.
- New field type “Number with letters (after №/No./#)”.
- Dates in words also in English (“5 March 2025”, “March 5, 2025”), net weight in kg also as “Net weight … kg”.
- Decimal separator follows the interface language (comma for Russian, dot for English).
- Zone labels drawn above the frames, not over the text.
- Settings and templates are saved next to the .exe when built with PyInstaller.
- Rewritten user guide (Help → User guide, F1).
- Removed company-specific processors and branding.
